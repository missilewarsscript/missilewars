## 🛠️ Troubleshooting Common Issues

**❌ Script GUI Does Not Appear After Injection**
The executor may not have attached before the game fully loaded.
**Solution:** Wait until you are fully inside a server and can move your character before hitting Execute in your executor.

**❌ Infinite Cash Not Working**
This module occasionally requires a fresh session if the game patched its economy handler.
**Solution:** Rejoin the server, re-inject the **Missile Script**, and enable Infinite Cash from a clean session rather than a carried-over one.

**❌ Auto Farm Stops Mid-Session**
The farm loop can break if the game removes the resource type it was targeting.
**Solution:** Toggle Auto Farm off and back on — this forces the script to re-scan for active resource nodes in the current map state.

**❌ Executor Crashes When Injecting on Windows**
Almost always caused by missing Administrator privileges.
**Solution:** Right-click your executor `.exe` at `C:/Desktop/MissileWars/` and select **Run as Administrator** before launching Roblox.

**❌ ESP Labels Appear but Are in Wrong Positions**
This happens when screen resolution or GUI scale mismatches the render layer.
**Solution:** Set `gui_scale` to `1.0` in `config.lua` and restart the script — then adjust up from there incrementally.

**❌ Anti-AFK Kicked Despite Being Enabled**
Some servers use custom kick timers shorter than the standard Roblox timeout.
**Solution:** Reduce the Anti-AFK heartbeat interval in settings from 8 minutes to 4 minutes for servers with aggressive idle checks.

## ❓ FAQ

### Does the Missile Wars Script work after Roblox updates?
In almost every case, yes — updates are pushed to the **Missile Script** within 24 to 48 hours of any Roblox patch that affects behavior. The team monitors patch notes closely, and core modules like **Auto Farm** and **Infinite Cash** are the first to be re-validated after any engine change.

### Can I use this on a phone and a PC with the same config?
Absolutely. The `config.lua` format is identical across platforms. Copy your tuned config file from `C:/Desktop/MissileWars/config.lua` to your device's executor config folder and your preferences will carry over exactly — keybinds, GUI theme, and all toggles included.

### Why does Kill All sometimes only affect part of the server?
The **Kill All** function operates in batches when the server population is above a certain threshold. This is an intentional design choice to avoid the operation generating a detectable spike in network traffic. You can fire it a second time to catch any remaining targets that the first pass missed.

### Is there a way to run Auto Farm without the GUI being visible?
Yes — the **Missile Wars Script** supports a minimized mode where only a small indicator dot remains on-screen while the GUI is hidden. Press your configured `keybind_toggle_gui` key (default `RightShift`) to collapse the panel completely without disabling any active features.

### Does the script work in private servers?
Every feature in the **Missile Script** works identically in private servers as it does in public ones — there is no functional difference in how modules behave. Private servers are actually a great place to test new feature combinations before using them in a competitive environment.
